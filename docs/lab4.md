## 实验任务

在已完成实验三的 Ubuntu 虚拟机上工作。可以在家目录新建 `linux-labs/lab4` 目录保存三个脚本。每个脚本第一行写 `#!/usr/bin/env bash`，保存后先用 `bash -n 文件名` 检查语法，再用 `bash 文件名` 运行。以下代码片段用来说明关键判断，请补齐自己的脚本并验证。

## 1. 判断用户名与 sudo 权限

1. 用 `read -r -p '用户名：' name` 读取输入。对空输入输出提示并退出。用 `getent passwd "$name"` 的退出状态判断账号是否存在，避免把 `zs` 误当成 `zs123`。
2. 若账号存在，在本实验 Ubuntu 默认授权下，可先用 `id -nG "$name"` 观察组。为覆盖单独写入 sudoers 的授权，再用 `sudo -l -U "$name"` 检查规则，区分所有命令、指定命令和无授权。执行检查的账号需能通过 sudo 查询他人权限。
3. 对不存在的账号，询问“是否创建？[y/N]”。用 `case` 分支：仅明确输入 `y` 或 `Y` 时调用 `sudo adduser "$name"`，其余输入显示“已取消”。创建完成后再用 `getent passwd` 核验。
4. 用真实输出填写下面的测试表，报告须同时呈现成功和不成功的分支。请选用专门的测试用户名。

| 测试输入 | 要观察的现象 |
| --- | --- |
| 实验二的新用户 | 存在，可看到 sudo 授权 |
| 虚拟机中存在的普通账号 | 存在，显示其实际授权情况；选用一个无 sudo 权限的测试账号验证此分支 |
| 不存在的用户名，选择 N | 不创建，再次查询仍不存在 |
| 不存在的用户名，选择 y | 完成交互创建，查询能看到新账号 |

## 2. 读取 Nginx 配置并备份网站

请以自己的普通账号运行备份脚本，让 `$HOME/backup` 指向自己的家目录。脚本须逐步打印“目录是否存在、实际站点根目录、归档完整路径”，并在归档成功后核验内容。

**先找备份目录。** 用 `[[ -d "$HOME/backup" ]]` 判断。若存在，输出“复用现有目录”；否则先 `mkdir -p "$HOME/backup"` 再输出“已创建”。连续执行两次以观察不同分支。

**再从配置读站点根目录。** 实验三使用的默认站点只有一条有效的 `root` 指令，且路径不含空格。下面的写法适用于这份配置。在其他站点或多条 `root` 指令的环境中，应先选定要备份的 server 块，并解释你如何识别它。

```bash
site=/etc/nginx/sites-enabled/default
webroot=$(awk '$1 == "root" {p=$2; sub(/;$/, "", p); print p; exit}' "$site")
if [[ -z "$webroot" || "$webroot" == / || ! -d "$webroot" ]]; then
    printf '无法确认站点目录：%s\n' "$webroot" >&2
    exit 1
fi
printf '站点根目录：%s\n' "$webroot"
```

**最后归档。** 将归档保存在 `$HOME/backup`。用日期命名；如果需要同日重复测试，可增加时分秒。`tar -C` 能让归档保留相对路径。若目录内有仅限服务账号读取的配置文件，可只给 `tar` 提升读取权限，归档文件仍由普通用户的 Shell 创建。归档可能含数据库口令，请保留在虚拟机中。

```bash
umask 077
archive="$HOME/backup/$(date +%F-%H%M%S).tar.gz"
if sudo tar -czf - -C "$webroot" . > "$archive"; then
    printf '备份完成：%s\n' "$archive"
    tar -tzf "$archive" | sed -n '1,10p'
else
    rm -f -- "$archive"
    printf '备份失败，请检查目录和权限。\n' >&2
    exit 1
fi
```

截图中要能同时追溯源目录和归档路径；从归档目录清单中指出 phpMyAdmin 或博客的一个文件，说明它确实进入备份。

## 3. 统计本实验网段内响应 Ping 的主机

报告中的“C 类网”在本实验按指定 IPv4 `/24` 网段处理。先用 `ip -br -4 addr` 确定**自己虚拟机的实验网卡**和前缀长度。若使用 VirtualBox 仅主机网，通常能看到宿主机和虚拟机的接口；若实际地址不是 `/24`，请与教师核对本次练习范围。

下例仅演示已核定的教学隔离网段 `192.168.56.0/24`。替换为本组教学虚拟网的前三段。循环访问主机号 1～254，单个地址发送一次 ICMP Echo 请求；超时后继续。输出应给出响应地址和最终计数。

```bash
prefix=192.168.56
count=0
for host in {1..254}; do
    addr="$prefix.$host"
    if ping -n -c 1 -W 1 "$addr" >/dev/null 2>&1; then
        printf '响应：%s\n' "$addr"
        count=$((count + 1))
    fi
done
printf '%s.0/24 中有 %d 个地址响应 Ping\n' "$prefix" "$count"
```

逐地址等待可能持续数分钟。用已知开机的实验机验证一次，并记录你选择的网卡、网段和响应数量。能响应 Ping 的主机数受防火墙和网络状态影响，实验结论请写成“本次有多少地址响应”。
