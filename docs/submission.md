## 报告怎么写

1. **封面**：填写课程名称、实验项目、学院、专业班级、学号、姓名、实验日期及指导教师等信息。成绩和得分栏留给教师填写。使用 WPS 保存后，封面排版可能发生变化。提交前请用 Microsoft Word 打开最终文件，对照模板检查标题、表格和分页。
2. **实验过程及结果**：按各章任务顺序编写。标注“命令”的地方，须用可复制文本写出实际命令；标注“截图”的地方，应提供完整操作过程及结果的截图。标注两者时请同时提供。每张图配一句说明，指出读者应核对的具体字段。
3. **遇到的问题及解决方法**：从自己的实验记录中写出现象、排查依据、修正动作和复查结果。如果过程顺利，可以写你如何验证关键环节。删除模板中的占位文字。
4. **实验心得**：选取一次实际操作，说明你掌握了什么、下次如何更快判断问题。例如用哪项检查区分 Nginx 的路径错误和 PHP-FPM 连接失败。
5. 实验四、五须把完整脚本以**文字**放入报告，同时提交相应源文件。实验五还要对脚本作详细注释或在报告内说明。截图时保留本次操作的命令、路径和结果。

## 每张截图如何验收

**截屏时你在显示屏上看到的内容，都要完整出现在图中。** 请对照顶部标题栏、虚拟机窗口、底部任务栏和右下角时间逐一检查。只截终端、虚拟机窗口、网页正文或某个结果框，都缺少屏幕其余部分。

1. **查范围。** 打开原始图片，查看四边和四角。截图时可见的桌面、任务栏、菜单栏、标题栏和地址栏都应保留。全屏控制台本来就没有桌面栏时，保留整个控制台。
2. **查内容。** 命令截图看得清“谁执行、执行了什么、返回什么”，网页截图看得清地址和结果。输出超过一屏时，滚动后补拍一张全屏图，相邻两张保留几行相同内容。
3. **排进 Word。** 用“插入 → 图片”选择原图，锁定纵横比适配页宽，保留四边。要强调字段或结果，请在全屏图上叠加红色空心矩形。图下注明“实验步骤、操作对象、实际结果”。例如“实验二，第 4 步：以本人新账号通过 SSH 登录后，`sudo su` 成功，`whoami` 返回 `root`。”命令文本另列，图片小到难辨时可用横向页面或把步骤分图。

## 命名与上交

- 报告使用 **Microsoft Office 365 可以打开的 `.doc` 或 `.docx`**。请用“另存为”选择正确格式，改完后重新打开核验。随意改后缀导致打不开，按未提交处理。
- 文件名按 **学号+姓名+实验编号**，加号保留。单项示例为 `2020011123+张三+实验2.docx`。若按安排合交本指导书全部五项，可写 `2020011123+张三+实验1-5.docx`。原报告模板示例中的 `实验1-6` 仅用于演示命名，编号范围按实际提交内容填写。命名不规范按未提交处理。
- 有脚本等配套材料时，将报告、源文件和所需资源放进**与报告同名（不含扩展名）**的文件夹。交给班长或负责人时**不打包**。例如文件夹 `2020011123+张三+实验4` 内含同名 Word 报告及三个 `.sh` 文件。
- 在教师指定时间内交班长或负责人收齐，由其按班级统一提交实验指导教师。以课堂通知的截止时间为准。
