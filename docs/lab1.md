## 实验任务

安装 VMware Workstation 或同类软件，创建虚拟机并使用英语安装 Linux。后续示例以 Ubuntu Server 22.04 LTS 为基准，报告模板亦列出 Ubuntu 20.04 LTS。按课程安排，安装纯命令行系统或选用非 Ubuntu 发行版可获得加分，请在报告中注明所选系统和安装方式。

## 1. 准备虚拟机

1. 在宿主机安装 VMware Workstation 或 VirtualBox，打开软件并截取主界面。宿主机是你的物理电脑，以下系统安装、分区与配置都在新建虚拟机中完成。
2. 从 Ubuntu 官方镜像站下载与 CPU 架构相符的 Server ISO。新建虚拟机，选择 Linux 和对应架构。若软件提供无人值守安装，请选手动安装，以便在创建用户和确认安装时截图。
3. 分配 **2 个虚拟 CPU 核心、2 GB 内存**。报告模板给出的下限为 1 核、0.5 GB，但现代安装器在低内存下可能无法启动。磁盘可选约 25 GB 动态分配，网络先选 NAT；后续要从宿主机访问时，可增配仅主机网卡。
4. 将 ISO 挂载到虚拟光驱。开机前截取虚拟机配置页，使 CPU 核心数和内存同时可见。

## 2. 安装并建立个人账号

1. 从 ISO 启动，在语言界面选择 **English**，确认键盘布局。网络使用 DHCP，若课堂没有代理，可留空代理地址。
2. 在存储布局页辨认刚创建的虚拟磁盘，核对容量。可以使用整块虚拟磁盘。**在确认写入前截图**，画面应包含将要应用的安装配置或分区摘要。不同版本可能先确认分区，再创建账号。
3. 在身份设置页填写姓名、主机名和用户名。**用户名使用本人姓名拼音首字母，密码按原报告填写本人学号。** 例如张三的用户名为 `zs`。截取能看见用户名的界面，密码保持遮蔽。该口令只用于本地隔离的教学虚拟机。
4. 等待安装结束，移除 ISO 后重启。出现 `login:` 时输入刚建立的账号。输入密码时终端不会回显字符，输入后按回车即可。

## 3. 登录后核验

在虚拟机内逐行执行，记录与自己的配置相符的结果。

```bash
whoami
cat /etc/os-release
lscpu | grep -E '^CPU\(s\):'
free -h
lsblk
ip -br address
```

`whoami` 应输出自己的姓名首字母。`free -h` 显示的可用总内存可能略小于配置值。最后一条命令列出网卡地址，记录非 `lo` 的 IPv4 地址，供实验二连接使用。可在关机后保留一个干净快照，供实验五重新部署。

| 环节 | 报告应呈现的证据 |
| --- | --- |
| 虚拟机软件 | 安装或运行成功的截图 |
| 创建及安装 | **至少 3 张**，分别呈现机器配置、创建用户界面、安装信息确认页；用户名可辨认 |
| 结果说明 | 写明实际系统版本、安装方式、用户名及验证结果。登录后的截图可补充安装证据 |

**遇到问题时**，若重启后再次进入安装器，检查虚拟光驱是否已卸载；若安装过程中卡住，先核对内存与 ISO 架构。把实际观察、处理动作和复查结果写进报告。
