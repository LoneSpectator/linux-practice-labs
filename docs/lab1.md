## 实验任务

安装 VMware Workstation 或同类软件，创建虚拟机并使用英语安装 Linux。本指导书默认使用 Ubuntu Server 24.04 LTS；已安装 26.04 LTS 的同学沿用现有虚拟机。按课程安排，安装纯命令行系统或选用非 Ubuntu 发行版可获得加分，请在报告中注明所选系统和安装方式。

> **本章截屏**　请在宿主机截取整块实验显示屏，保留虚拟机窗口及其周围可见的桌面、任务栏和时间。安装向导里的两处画面一旦点过就难以重现，先存图再继续。[查看安装界面图例](screenshots.html#installer)

## 1. 准备虚拟机

1. Windows 宿主机默认使用 VMware Workstation，安装后打开主界面并截屏。已使用其他虚拟机软件的同学沿用现有环境。宿主机是你的物理电脑，以下系统安装、分区与配置都在新建虚拟机中完成。
2. 新建环境时，从 Ubuntu 官方镜像站下载与 CPU 架构相符的 Ubuntu Server 24.04 LTS ISO。新建虚拟机，选择 Linux 和对应架构。若软件提供无人值守安装，请选手动安装，以便在创建用户和确认安装时截图。
3. 分配 **2 个虚拟 CPU 核心、2 GB 内存**。报告模板给出的下限为 1 核、0.5 GB，但现代安装器在低内存下可能无法启动。安装 Desktop 的同学按桌面镜像要求分配内存（例如 26.04 Desktop 为 6 GB）。磁盘可设为 25 GB 或更大，动态分配，网络先选 NAT；后续要从宿主机访问时，可增配仅主机网卡。
4. **以 VMware Workstation 为例。** 选择“文件 → 新建虚拟机 → 典型 → 稍后安装操作系统”，选择 Linux 和与镜像匹配的 Ubuntu 版本。给虚拟机命名，选好存放虚拟磁盘的目录。在最后一页进入“自定义硬件”，依次设置内存、处理器、网络及 CD/DVD。以 1 个处理器、每个处理器 2 核为例，总计 2 个虚拟 CPU 核心。CD/DVD 选“使用 ISO 映像文件”，勾选“启动时连接”。
5. **使用 VirtualBox 的同学。** 进入“新建”，选择 ISO，启用“跳过无人值守安装”（若该版本提供此选项）。在“硬件”页设置内存和处理器，在“虚拟硬盘”页创建新磁盘，先查看“摘要”再完成。
6. **此时截屏。** 在宿主机打开机器摘要，保留软件名称、虚拟机名称、CPU 核心数和内存。字段分散在两个页面时，分别截取两张全屏图。将这组图片与“虚拟机软件已安装”的主界面图区分开。

## 2. 安装并建立个人账号

1. 从 ISO 启动，在语言界面选择 **English**，确认键盘布局。网络使用 DHCP，若课堂没有代理，可留空代理地址。
2. 在存储布局页辨认刚创建的虚拟磁盘，核对容量。可以使用整块虚拟磁盘。**在确认写入前截图**，画面应包含将要应用的安装配置或分区摘要。不同版本可能先确认分区，再创建账号。
3. 在身份设置页填写姓名、主机名和用户名。**用户名使用本人姓名拼音首字母，密码按原报告填写本人学号。** 例如张三的用户名为 `zs`。截取身份设置页的全屏图，用红框圈出用户登录名。
4. **停在两个取证点。** 在 Ubuntu Server 的 “Storage configuration / File system summary” 页，先读出目标虚拟磁盘和分区摘要，保存全屏原图后再选 “Done”；出现写盘确认时核对目标。到 “Profile setup” 页，分清显示姓名与 “Pick a username”，后者填写姓名首字母。保存全屏图，再选 “Done”。请在两张图下分别标注所确认的磁盘和登录用户名。
5. 等待安装结束，移除 ISO 后重启。出现 `login:` 时输入刚建立的账号。输入密码时终端不会回显字符，输入后按回车即可。

## 3. 登录后核验

等到虚拟光驱已弹出，登录个人账号。看到带用户名的 Shell 提示符后逐行执行以下命令。先核对用户和系统版本，再核对 CPU、内存、磁盘与网卡。将虚拟机设置页的核心数和系统内读到的核心数写在同一句图注里，方便对照。

```bash
whoami
cat /etc/os-release
lscpu | grep -E '^CPU\(s\):'
free -h
lsblk
ip -br address
```

`whoami` 应输出自己的姓名首字母。`free -h` 显示的可用总内存可能略小于配置值。最后一条命令列出网卡地址，记录非 `lo` 的 IPv4 地址，供实验二连接使用。可在关机后保留一个干净快照，供实验五重新部署。

| 虚拟机软件 | 安装或运行成功的截图 |

**遇到问题时**，若重启后再次进入安装器，检查虚拟光驱是否已卸载；若安装过程中卡住，先核对内存与 ISO 架构。把实际观察、处理动作和复查结果写进报告。
